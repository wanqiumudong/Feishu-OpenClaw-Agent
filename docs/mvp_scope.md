# MVP 范围

## 当前做什么

当前 bootstrap MVP 聚焦四个能力：

1. 带来源问答：基于 mock 数据和可选真实测试文档做关键词召回，输出简洁答案和来源列表。
2. 会前背景包生成：根据指定会议事件汇总会议目的、参会人、必读资料、关键决策、未关闭风险和待确认问题。
3. 会后 Action Items 抽取与任务预览：从会议纪要中抽取行动项，生成负责人、截止时间、背景资料和来源。
4. 推进总表/重点事项自动对账预览：对比任务、群聊线索和已有推进表，输出新增事项、状态更新、阻塞补全和来源归因。

## 当前不做什么

- 不做完整真实飞书组织接入；当前只验证了测试文档只读读取。
- 不接 OpenClaw channel。
- 不调用真实 LLM。
- 不创建真实飞书任务。
- 不写真实多维表格。
- 不做权限体系、多租户或线上服务。

## 验收边界

只要本地命令可以生成四类 Markdown 知识产物，测试可验证数据加载和 pipeline 可运行，并且真实测试文档可通过 `LarkCliProvider` 安全归一化，即满足当前 bootstrap 阶段目标。
