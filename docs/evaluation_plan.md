# Evaluation Plan

## 目标

评测目标不是证明系统已经接入真实飞书，而是验证 MeetingFlow Agent 在会议与项目推进场景中的输出是否准确、可追溯、可复现。当前阶段先做评测草案，后续再实现自动化评测系统。

## QA 准确性评测

记录字段：

- 问题
- 标准答案
- 实际答案
- 来源是否命中
- 是否幻觉
- 人工评分

判断标准：

- 答案必须引用当前数据中存在的来源。
- 不确定的信息应说明无法确认，不应补编。
- 评分建议 1-5 分：1 为错误，3 为部分正确，5 为准确且来源充分。

## 会前背景包评测

评测维度：

- 是否覆盖会议目标。
- 是否引用正确文档。
- 是否覆盖历史决策。
- 是否指出未关闭风险。
- 是否足够简洁，适合会前快速阅读。

## 会后行动项评测

评测维度：

- Action Item 是否抽对。
- 负责人是否抽对。
- 截止时间是否抽对。
- 背景链接是否正确。
- 是否适合创建任务。
- 是否错误抽取非任务型承诺句。

## 推进表对账评测

评测维度：

- 新增事项是否识别。
- 状态变化是否识别。
- 阻塞原因是否补全。
- 来源是否可追溯。
- 是否产生重复或低价值更新。

## 效率指标

建议对比人工与 Agent 两种方式：

- 手动查找资料耗时。
- Agent 生成耗时。
- 手动整理行动项耗时。
- Agent 抽取耗时。
- 用户人工确认时间。

当前阶段可先人工记录耗时，后续再加入自动计时。
