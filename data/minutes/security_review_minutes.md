# 安全评审会纪要

minutes_id: security_review_minutes
event_id: security_review
date: 2026-04-23

## 会议目标

确认权限边界、日志脱敏、外部客户会议处理规则和上线阻断条件。

## 参会人

何澈、周岚、林舟、王越、陈墨、苏晴

## 关键决策

- mock 数据不得包含真实 token、真实 user id、真实客户名称或真实企业数据。
- 外部客户会议默认只生成内部行动项，不把外部发言原文作为任务标题。
- 权限越权告警为 P0 阻断项，出现一次即停止放量。
- 日志只记录 source_id、规则名和 mock 请求编号，不记录私密字段。

## 讨论摘要

何澈指出“会前背景包”容易误把所有项目文档都暴露给参会人，因此需要按会议参与者和文档边界过滤。苏晴补充客服反馈材料必须先脱敏，只保留问题类型和处理建议。林舟确认复赛视频只演示 mock 数据，不接入真实 Feishu tenant。
